# FinGuard UI

Standalone frontend copy of FinGuard's redesigned interface. The workspaces, quiz, and sample results use browser-side demo data only; no backend or API is required.

## Run locally

From this folder, run:

```powershell
python -m http.server 5173
```

Then open `http://localhost:5173/` in a browser. Serving over HTTP is needed for the JavaScript modules.
